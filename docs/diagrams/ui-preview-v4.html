与设计稿的差异说明（图标替换，详见 DESIGN-UI-V4.md §8）

盾牌（设计稿为闪电）、齿轮、对勾、垃圾桶等以 AdSkipIcons 现有图标 / 占位符号代替，本预览中以 emoji 示意； 头像为首字符占位；品牌文案不出现「AdSkip」字样；其余布局、间距、配色、圆角、阴影、组件状态均按设计稿还原。
