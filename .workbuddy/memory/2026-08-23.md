### 坑：分支引用文件丢失
- 现象：`git commit` 成功输出 `[codex/github 8968eee]`，但随后的 push 报
  "src refspec codex/github does not match any"；`git branch -a` 看不到本地分支，
  HEAD 指向 unborn branch；reflog 有提交记录、commit 对象存在，
  但 `.git/refs/heads/codex/github` 文件未落盘
- 原因：`git update-ref` 也无法持久化嵌套目录 `.git/refs/heads/codex/` 下的引用
  （疑似环境文件系统对 .git 内新建子目录的写入被静默丢弃）
- 修复：手动 `mkdir -p .git/refs/heads/codex && printf '<sha>' > .git/refs/heads/codex/github`，
  引用恢复后 push 成功
- 复用结论：此环境若再遇到「commit 成功但 push 找不到分支」，直接手写 loose ref 文件
