功能

一个安装包 + 一个本地服务，覆盖跳过广告的全部环节

毫秒级自动跳过

监听窗口变化，广告出现的瞬间即找到「跳过」按钮并点击，无需手动。

双通道识别

文本关键词 + 控件 ViewID 两种匹配方式，纯图片按钮也能精准命中。

应用管理

按应用逐项开关自动跳过，各应用跳过次数一目了然。

跳过日志

最近 200 条跳过记录：时间、应用、包名，可随时清空。

云端规则同步

自建规则中心一键下发关键词、ViewID 与应用专属规则，多设备共享。

隐私安全

零第三方依赖，无账号体系，统计仅存本机与你自己的服务器。

工作原理

只点击广告界面本身展示的「跳过」按钮，不拦截、不破解任何内容

1

监听启动

无障碍服务接收应用窗口状态与内容变化事件。

2

识别按钮

遍历界面节点，文本关键词与控件 ID 双通道匹配「跳过」按钮。

3

模拟点击

优先执行节点点击，不可点击时按坐标派发模拟手势。

4

记录上报

本地写入日志与统计，静默上报自建服务端。
