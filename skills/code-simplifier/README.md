# Code Simplifier

A single-skill plugin for code reviews and readability improvements. It spots avoidable complexity while preserving behavior and following your project's existing workflow.

Install `code-simplifier` from [Langji AI Marketplace](https://github.com/langji3/langji-ai-marketplace) in Codex or Claude Code, then ask for a code review or an authorized simplification. Reviews report findings without changing files. See the [skill](SKILL.md) for its scope and examples.

To fork it, edit the skill and both plugin manifests, then run `python scripts/validate.py`. The [review scenarios](tests/scenarios.md), [attribution](NOTICE.md), and [Apache-2.0 license](LICENSE) are included.
